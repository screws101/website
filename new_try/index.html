How to Use Little Helper

  1. Start with the Meal Plan

    Head over to the Meal Plan page. Each day of the week has its own card, and each card includes four buttons: Breakfast, Lunch, Dinner, and Snack. These cards are your weekly meal prep guide.

    To get started, click a meal button for the day you want to plan. For example, if you only want to plan Sunday Breakfast, click the Breakfast button in Sunday’s card. This will take you to the Choose a Meal page.

  2. Choose or Create a Recipe

    On the Choose a Meal page, you’ll be prompted to either select an existing recipe or create a new one.

    If you're starting fresh, click Create a New Recipe. Fill in any details you know — don't worry if you leave some fields blank (like the URL), Little Helper will let you know if something important is missing.

    Want to keep things simple? Just paste a link to the recipe in the URL section so you can access it later. When you're done, click Create to save the recipe. You’ll be taken to the Recipes page.

  3. Use the Recipes Page

    Here, you’ll see a collection of all your recipes, including the one you just created. To add it to your meal plan, click the Add to Meal Plan button (with the plus icon). A pop-up will confirm that it’s been added.

    Use the Delete button to remove a recipe.

    Click Inspect to view full details like ingredients, steps, and notes.

    Later on, you can revisit this page to reuse recipes by clicking Choose Existing Recipe from the Choose a Meal page.

  4. Step 4: Return to the Meal Plan

    Back on the Meal Plan page, you’ll now see your selected recipe name in place of the meal button you clicked earlier.

    Click the recipe name to view its details again (ingredients, steps, link, etc.). To remove it from the plan, click the X icon next to the name.

    At the bottom of the page, there’s a Clear Meal Plan button — this removes all meals from all days in one click.

  5. Step 5: Keep Track of Your Pantry

    The Pantry page helps you monitor what you have and how much of it is available. Click Add a Pantry Item to go to the Add Ingredient page (similar to the recipe creation page).

    You can:

    Edit item quantities,

    Add items to your grocery list using the Add to Grocery List button on each pantry card. A pop-up will ask how much to add — enter the amount and confirm.

  6. Step 6: Manage Your Grocery List

    The Grocery List page keeps track of what you need to buy. Items from your pantry will appear here with the requested quantity.

    You can:

    Edit quantities (click the pencil icon),

    Delete individual items,

    Clear the entire list,

    Sort items alphabetically with the A–Z button,

    Add a new item manually using the Add Item button (enter name and quantity in the pop-up)

  7. Here are some recommended places to find recipes:
